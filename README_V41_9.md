# AQ V41.9 第一阶段 · 云端专业数据适配基础版

## 部署
1. 解压，将 `index.html` 上传覆盖 GitHub 仓库 `public/index.html`。
2. 将 `worker.js` 上传覆盖仓库根目录 `worker.js`。
3. 保留原有 `wrangler.toml`、D1配置、schema.sql、环境变量。
4. Cloudflare部署后检查网页版本 V41.9，以及 `/api/cr/status` 返回的 `ready:false`。

## 本阶段实际实现
- 增加独立CR-T接入状态面板和只读 `/api/cr/status` 数据契约。
- 非交易时段自动TOP3的“新入榜”改为“历史观察”，避免误认作实时新信号。
- 保留V41.8扫描、自选、持仓、手动TOP3及已有D1接口。
- 未获得专业逐笔数据授权前，CR-T始终不可用，绝不伪造分数。

## 尚未实现（重要）
- **尚未接入任何专业Level-2供应商**；不能计算真实CR-T/BPR/FCD。
- 未实现逐笔数据采集服务、后台自动复盘任务、次日行情验证和样本外回测。
- 原V41.8的分段扫描失败问题仍需线上排查；D1仍需用户自行绑定。
- 若数据供应商提供WebSocket或SDK，需额外常驻采集服务，不能只靠这两个静态文件。

## 供应商接入验收标准
- 个人用户授权、云服务器API使用、逐笔成交/委托字段、数据延迟、历史保存及衍生数据展示权利须书面确认。
- 禁止把普通快照成交额或软件显示的“主力净量”冒充逐笔主动成交。
- 先用20–50只股票进行数据质量、延迟、信号前瞻性和回撤的对照验证。

## 安全
- 不提供同花顺登录账号、交易密码或短信验证码。API密钥应放在Cloudflare Secrets或采集服务的密钥管理中。
