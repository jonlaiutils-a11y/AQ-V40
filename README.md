# AQ V40 P2 强势筛选测试版

基于已验证可返回报价的腾讯接口。预设观察池共 332 个代码，非全A股；可能包含停牌或无效股票，实际返回数以页面为准。

## 部署
在 GitHub AQ-V40 仓库根目录覆盖 worker.js、wrangler.toml 和 public/index.html（注意 public 目录）；Cloudflare 自动构建后刷新。

## 限制
- 不是全A股扫描，TOP80仅为预设池内排序。
- 不保证腾讯接口批量请求稳定，返回缺失时页面会标记不完整。
- AQ综合分、接力分、等级均为未经回测的启发式指标，不是概率。
- 缺少分钟线、盘口、真实成交量比，不给“可进”或买入价格。
- 页面更新时间是请求时间，非行情生成时间；非交易时段报价可能为昨日收盘。
- 建议先在交易时段核对行情并做模拟观察。
