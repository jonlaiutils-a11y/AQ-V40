# AQ V40 P4 渐进式候选代码空间扫描 Beta

## 部署
将本包全部文件上传替换 GitHub AQ-V40 仓库对应路径（worker.js、public/index.html、wrangler.toml），Cloudflare 触发部署。README 可选。

## 重要限制
- 扫描 13 个常见沪深京代码前缀、共 13000 个候选号码，**不等于** 13000 只上市股票，也不等于交易所官方完整名录。若存在未覆盖前缀或交易所规则变动，可能漏股。
- 每次 /api/segment 扫描 400 个候选号码，网页每4秒推进一批，约 33 批；实际耗时取决于腾讯公开接口，且可能限流。
- 页面只保留本轮有效报价及 Top80；关闭页面后进度不保存；完成前榜单不是全市场排名。扫描一轮后开始下一轮；不是所有股票同步的实时快照。
- 腾讯非官方公开接口可能不支持部分北交所股票；失败批次会显示警告，**不能**声称全市场完整。
- 非交易时段为最近收盘行情，数据更新不等于价格在更新。
- 目前仅为观察和接口稳定性测试，无分钟线、盘口或已回测概率，**不可据此下单**。
- 下一步应接入权威上市证券名录，增加持久化缓存、定时后台扫描和断点续扫，随后验证全市场覆盖率。
