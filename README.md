# AQ V40 P1 — 行情接口验证版

## 本版已实现
- Cloudflare Worker 后端代理行情，避免前端直接跨域请求。
- 尝试分页获取沪深A股公开行情快照；去重、缺页检测、异常返回提示。
- TOP80 启发式观察排名；30秒刷新；北京时间时间戳；手机/iPad横向表格。
- 不完整数据警告；数据不可用时不展示旧数据作为新数据。

## 本版未实现（不能用于真实交易决策）
- 经许可的可靠实时行情、分钟级K线、盘口与逐笔成交。
- 涨停概率、次日上涨概率的训练、样本外验证和概率校准。
- 真实可交易买点、止损和持仓监控。
- 全A股覆盖率尚需核验；当前上游证券类型过滤器可能遗漏部分股票。

## 部署（Cloudflare Workers）
1. 将本ZIP解压后上传到GitHub仓库，保持 `worker.js`、`wrangler.toml`、`public/index.html` 路径不变。
2. Cloudflare 控制台 → Workers & Pages → Create → Import a repository，选择该仓库。
3. 选择 Worker 项目（不是纯静态 Pages）。如需填写构建命令：`npx wrangler deploy`；也可在本地安装 Node 后执行 `npx wrangler deploy`。
4. 部署后访问分配的 workers.dev 域名，检查 `/api/health` 和 `/api/scan`。
5. 如果公开行情上游限流/封禁，会出现503，需更换合规稳定的数据供应商；不能以测试接口充当正式实盘数据。

## 重要说明
上游为东方财富公开行情接口（非官方开发者服务）。接口格式、许可和可用性均可能改变。此代码仅用于技术验证，不保证部署时可以成功抓取；不提供收益保证。
