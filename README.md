# AQ V40 P7 Ranking + CR Data Gate Beta

基于P6的分段腾讯报价扫描改造。**仅用于研究测试，非交易系统。**

## 本版实际功能
- 延续P6的13,000个候选代码空间分段扫描（包含大量无效/未上市代码，并非官方证券名录）；交易时段每4秒扫描400个代码，整轮扫描时间较长。
- 综合TOP30、早期启动、强势延续、冲板观察榜单；每120秒固定重排（切换榜单类型时即时重排）。
- 对当前榜单TOP30独立调用`/api/quotes?codes=`，目标每5秒更新报价；报价更新不会重排榜单。腾讯非官方接口可能限流，5秒不是交易所实时保证。
- CR资金承接明确标记“待接入”：无分钟线/逐笔数据，**不计算虚假的CR分数**；不输出买入确认和次日上涨概率。
- 可选Cloudflare D1保存每个交易日首次入榜时间、首次价格、最佳排名、最新报价及观察期峰谷价格（仅为快照，不代表盘中真正最高/最低）。所有曾进入TOP3的股票可通过`/api/history?day=YYYY-MM-DD`查询（以`best_rank<=3`筛选）。

## 部署
1. 将`worker.js`、`wrangler.toml`、`public/index.html`上传到现有Cloudflare Workers仓库并部署。
2. **强烈建议配置D1，否则不会持久保存历史**：Cloudflare创建D1数据库`aq-v40-history`，在Worker设置中绑定变量名`DB`。使用D1控制台执行`schema.sql`中的SQL。若使用Wrangler CI部署，请在`wrangler.toml`追加：

```toml
[[d1_databases]]
binding = "DB"
database_name = "aq-v40-history"
database_id = "替换为Cloudflare控制台的真实数据库ID"
```

3. 确认`/api/health`、`/api/universe`、`/api/quotes?codes=002787`以及`/api/history?day=2026-10-22`响应。历史接口未配置D1会返回503，这是正确的保护行为。
4. 盘中观察榜单，收盘复盘时读取D1历史表中`best_rank<=3`的股票。**外部ChatGPT定时复盘任务尚未自动连接到D1**；需要可访问的历史API和明确授权后才能真正读取历史。不要将任务设置成功等同于已完成数据接入。

## 目前缺失及风险
- 未接入交易所授权分钟线、逐笔主动成交、真实量比、板块数据及涨停封单；CR、精确买点、次日概率不可验证。
- D1写入由浏览器榜单触发；页面关闭后不会持续扫描和写入，不能称为无人值守后台复盘。下一阶段需要Cloudflare Cron+持久化扫描状态或专门数据服务。
- 评分是启发式而非回测成果；腾讯公开接口存在中断、延迟和合规风险。行情时间以接口字段为准。
- `schema.sql`为新增文件，必须在D1执行；Worker无数据库时会继续显示报价榜单，但不保存历史。
