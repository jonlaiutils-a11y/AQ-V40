# AQ V41.0 · Verified Data Gate / 盘中候选雷达

这是在用户上传的 AQ V40 P7 源码基础上升级的**可部署测试版**，不是已验证可盈利的交易系统。

## V41本次已实现
- 过滤明显退市/ST/退市整理及无有效当日行情时间的报价；避免历史报价/占位数据混入当天榜单。**不等同于官方上市股票名录**。
- 整轮扫描完成状态与完成轮数可见；未扫完前提示TOP3只是已扫描样本的排名。
- 保留每120秒榜单重排与盘中目标每5秒TOP30报价刷新；接口可能延迟/限流。
- D1新增 `aq_top3_events`：每个交易日首次进入TOP3的股票记录一次；提供 `/api/top3-history?day=YYYY-MM-DD` 和页面查询表。
- `/api/diagnostics` 公开数据能力缺口和D1绑定状态。
- 保留真实数据门禁：无分钟/逐笔数据，不伪造CR、真实量比、次日概率、买入点或目标价。

## Cloudflare Workers部署
1. 将本ZIP全部文件解压到原项目，覆盖 `worker.js`、`public/index.html`、`schema.sql`、`wrangler.toml`。
2. 如果已创建D1数据库，在原D1控制台执行 `schema.sql`（CREATE IF NOT EXISTS，不删除旧记录）。
3. 确认 Worker `DB` 绑定对应真实D1；如果使用wrangler部署，请在 wrangler.toml 增加：
```
[[d1_databases]]
binding = "DB"
database_name = "你的真实D1数据库名"
database_id = "你的真实D1数据库ID"
```
4. 重新部署，打开 `/api/health`、`/api/diagnostics`、`/api/top3-history?day=2026-10-23` 测试。
5. 页面必须保持打开才会持续扫描和触发写入；浏览器关闭后不会自动复盘。历史数据库记录是报价快照，不是官方收盘价。
