基于P4版本增量修改。保留腾讯行情接口、13,000个候选代码空间、33批渐进扫描和TOP80。

## 本版改动
- TOP3使用综合评分和接力评分联合排序。
- 午后雷达仅北京时间13:00—15:00启用，使用不同的候选规则，并从展示中排除TOP3重叠股票。
- 未接入分钟线、逐笔成交、盘口和封单，因此不产生可进/买入价等信号。

将 worker.js、public/index.html、wrangler.toml 上传并覆盖原GitHub仓库对应路径，等待Cloudflare部署完成。不要把README当作worker脚本。
